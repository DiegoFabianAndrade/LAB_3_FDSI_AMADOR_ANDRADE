### Descripción
Laboratorio académico orientado al análisis de seguridad de aplicaciones web y simulación de un sistema de gestión de incidentes basado en CrowdStrike Incident Hub.

El laboratorio contempla actividades de modelado de amenazas, análisis de tráfico HTTP, detección de vulnerabilidades y aplicación de controles de seguridad.
